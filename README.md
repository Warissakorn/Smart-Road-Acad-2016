# Smart Road 2.2 สำหรับ AutoCAD 2016

รองรับ AutoCAD 2016 รุ่นเต็มบน Windows ใช้ AutoLISP และ Visual LISP/ActiveX โดยโหลดไฟล์ `Smart Road.lsp` ได้โดยตรง

## ติดตั้ง

- ใช้ `APPLOAD` แล้วเลือก `Smart Road.lsp` จากโฟลเดอร์ที่เชื่อถือได้ตามการตั้งค่า `TRUSTEDPATHS`
- สำหรับโหลดอัตโนมัติ ให้ปิด AutoCAD แล้วคัดลอกโฟลเดอร์ `SmartRoad.bundle` ทั้งโฟลเดอร์ไปไว้ใน `%APPDATA%\Autodesk\ApplicationPlugins` หากลงรุ่นเดิมไว้ ให้แทนที่โฟลเดอร์เดิมด้วยโฟลเดอร์รุ่นนี้ จากนั้นเปิด AutoCAD ใหม่

### ตัวติดตั้ง Windows จาก GitHub Actions

เปิดแท็บ **Actions → Build Smart Road installer** เพื่อดาวน์โหลดไฟล์ `Setup.exe` หรือ ZIP จากหัวข้อ **Artifacts** ของงานที่ผ่านแล้ว Workflow ทำงานเมื่อ push เข้า `main` และเรียกด้วย **Run workflow** ได้ เมื่อ push แท็กที่ตรงกับ `AppVersion` ใน manifest เช่น `v2.2.0` workflow จะเผยแพร่ทั้งสองไฟล์ใน GitHub Releases

ปิด AutoCAD ก่อนเปิด Setup ตัวติดตั้งใช้โฟลเดอร์ Bundle เดิมสำหรับบัญชี Windows ปัจจุบันและใช้รายการถอนการติดตั้งเดิมเมื่ออัปเกรดจาก Setup รุ่นก่อน หากพบ Bundle ที่เคยคัดลอกจาก ZIP ก็จะแจ้งก่อนลงทับ ไฟล์อื่นในโฟลเดอร์ที่ตัวติดตั้งไม่ได้จัดการจะยังอยู่ ข้อมูลใน DWG และแม่แบบที่บันทึกในโปรไฟล์ AutoCAD ไม่ต้องย้าย

## แถบเครื่องมือ Smart Road

เมื่อติดตั้งด้วยโฟลเดอร์ `SmartRoad.bundle` แถบเครื่องมือจะถูกสร้างและแสดงด้านบนเมื่อโหลดครั้งแรก หากปิดแถบไป ให้พิมพ์ `SMARTROADTOOLBAR` เพื่อเปิดอีกครั้ง

หากโหลดไฟล์ LSP ด้วย `APPLOAD` จากตำแหน่งอื่น ให้พิมพ์ `SMARTROADTOOLBAR` หากมีหน้าต่างเลือกไฟล์ ให้เลือก `SmartRoadConnect16.bmp` ในโฟลเดอร์ `SmartRoad.bundle/Contents/Icons` เก็บไฟล์ไอคอนทั้งหมดไว้ด้วยกัน

- **Smart Road Settings** เปิดหน้าต่างตั้งค่าด้วยคำสั่ง `SMARTROAD`
- **Draw Road** เรียก `DROAD` เพื่อวาดแนวศูนย์กลางใหม่
- **Select Centerlines** เรียก `RNET` เพื่อสร้างถนนจากแนวเดิม

## เชื่อมขอบถนนในแบบเดิม

1. กด **Connect Edges** (`SRCONNECT`) แล้วคลิกขอบถนนสองเส้นตรงด้านที่ต้องการเก็บไว้ เครื่องมือใช้แนวเส้นจริงใน DWG เพื่อหามุมที่จะเชื่อม
2. ตรวจเส้นตัวอย่างแล้วเลือก **Apply** เพื่อยืนยัน หรือกด Esc เพื่อยกเลิก ใช้ `U` ครั้งเดียวเพื่อย้อนการแก้มุมนั้น
3. ทำซ้ำที่มุมอื่นของสามแยกหรือสี่แยกตามต้องการ

รองรับขอบที่วาดด้วย LINE และ LWPOLYLINE แบบเส้นตรงบนระนาบแนวนอนเดียวกัน โปรแกรมตัดส่วนเกินที่ตัดกัน หรือยืดช่วงตรงที่ปลายเส้นไปหาจุดตัด โดยแจ้งระยะยืดในภาพตัวอย่าง สำหรับเส้นที่ Smart Road สร้าง โปรแกรมเก็บข้อมูลแนวต้นทางไว้และทำเครื่องหมายมุมที่ตัดแล้ว หากสร้างช่วงที่แก้ใหม่ภายหลัง โปรแกรมจะแจ้งก่อนแทนที่งานตัดมุมนั้น มุมโค้งใช้กับคู่เส้นทั่วไปที่มีระยะพอสร้างรัศมีได้

## สรุปปริมาณ 2D

กด **Quantities** (`SRQUANTITY`) เพื่อสรุปแล้วเลือกว่าจะวางตารางใน DWG ส่งออก CSV หรือส่งออกทั้งสองแบบ

- **Corridors** เลือกแนวอ้างอิงหรือเลือกขอบจาก Smart Road เพื่อค้นหาแนวต้นทาง โปรแกรมนับแนวเดียวกันครั้งเดียวแม้เลือกทั้งแนวและขอบ วัดความยาวแนวอ้างอิงและความยาวขอบด้านนอกของแต่ละองค์ประกอบในแบบแยกตามชนิด ส่วนพื้นที่แปลนคำนวณจากแนวตามยาวและขอบของแต่ละองค์ประกอบเมื่อยืนยันขอบเขตครบได้
- **Existing** เลือกเส้นหรือรูปปิดจาก DWG ได้โดยตรง รายงานแยกตามเลเยอร์ เส้นเปิดมีความยาว ส่วนรูปปิดมีเส้นรอบรูปและพื้นที่เมื่อ AutoCAD อ่านพื้นที่ได้

ความยาวใช้หน่วยของแบบ พื้นที่ใช้หน่วยของแบบยกกำลังสอง พื้นที่เป็นผลรวมของแนวหรือรูปที่เลือก ให้ตรวจส่วนที่ซ้อนกันก่อนใช้เป็นปริมาณโครงการ เมื่อตัดขอบที่ทางแยกหรือรูปขอบไม่ครบ โปรแกรมยังวัดความยาวที่มีอยู่ในแบบได้ แต่เว้นพื้นที่ที่ยืนยันขอบไม่ได้ ตารางที่วางเป็นผล ณ เวลาที่สั่ง หลังแก้แบบให้เรียกคำสั่งอีกครั้งเพื่อออกรายงานล่าสุด เลือกชื่อไฟล์ใหม่เมื่อส่งออก CSV การใช้ `U` จะย้อนการวางตารางใน DWG และไฟล์ CSV ที่สร้างไว้ยังอยู่

## ขั้นตอนแบบเร็ว

### สร้างถนนและทางเท้าหลายแนว

1. ตั้งหน้าตัดครั้งแรกด้วย `SRPROFILE` หรือเปิด **Smart Road Settings → Quick Profile** หน้าต่างแสดงองค์ประกอบซ้าย–ขวาพร้อมกัน แก้ชนิด ความกว้าง และลำดับได้จากหน้าต่างเดียว
2. เลือกแนวเปิดใน Model Space หลายเส้น แล้วกด **Quick Build** (`SRQUICK`) โปรแกรมสร้างจากหน้าตัดล่าสุด ถ้ากดคำสั่งก่อนเลือกแนว จะเข้าสู่โหมดเลือกแนวได้เลย
3. ใช้ `U` ครั้งเดียวเพื่อย้อนการสร้างทั้งชุด แนวที่สร้างถนนไว้แล้ว แนวปิด หรือแนวที่อยู่บนเลเยอร์ล็อกจะถูกข้ามและรายงานจำนวน

การสร้างถนนด้วย **Road Corridor**, **Walkway** หรือ **Transit** จากหน้าตัดสำเร็จ จะบันทึกหน้าตัดนั้นสำหรับ Quick Build ครั้งถัดไปด้วย ค่าเริ่มแรกหากยังไม่เคยตั้งหน้าตัดคือช่องกว้าง 3.5 หน่วยฝั่งละหนึ่งช่อง

### คลิกกำหนดช่วงแก้หน้าตัด

1. กด **Pick Section** (`SRSECTION`) เลือกแนวอ้างอิงของถนน แล้วคลิกจุดต้นและจุดปลายช่วงบนแบบ โปรแกรมฉายตำแหน่งเข้าหาแนวและคำนวณระยะตามแนวให้
2. เลือก **Bus**, **Walkway**, **Parking** หรือ **Cycle** เพื่อเพิ่มองค์ประกอบที่ด้านนอกหน้าตัด หรือเลือก **Profile** เพื่อแก้รายการทั้งหมด กำหนดฝั่ง ความกว้าง และความยาวช่วงเปลี่ยนความกว้างตามลำดับ
3. ตรวจเส้นตัวอย่างแล้วกด **Build** หรือ **Cancel** หากช่วงที่เลือกทับช่วงที่กำหนดไว้แล้ว โปรแกรมให้ยืนยันก่อนแทนที่ช่วงเดิมทั้งช่วง

การแก้แบบจะเก็บช่วงที่ไม่เปลี่ยนไว้ เส้นเดิมที่พาดผ่านขอบเขตช่วงแก้อาจต้องแบ่งและสร้างใหม่ เมื่อแก้แนวที่สร้างด้วยรุ่นเก่าครั้งแรก หรือแนวที่ถูกปรับรูปทรงจากครั้งก่อน โปรแกรมจะสร้างขอบของแนวนั้นใหม่ทั้งหมดหนึ่งครั้ง ใช้ **Edit Corridor → Section** สำหรับงานที่ต้องป้อนระยะตัวเลขโดยตรง

## เครื่องมือวางแปลน 2D

| ปุ่ม | คำสั่ง | รูปแบบ |
|---|---|---|
| Road Corridor | `SRROAD` | ถนนทางเดียว สองทาง มีเกาะกลาง หรือถนนพร้อมช่องจอด ช่องจักรยาน คันหิน และทางเท้า |
| Walkway | `SRWALK` | ทางเท้าข้างเดียว สองข้าง หรือทางเดินอิสระ รวมถึงทางข้าม เกาะพัก และสัญลักษณ์ทางลาด |
| Transit | `SRTRANSIT` | ช่องรถเมล์ ช่อง BRT แนวรางเดี่ยวหรือรางคู่ ตำแหน่งป้ายหยุดรถ และชานชาลา |
| Junction | `SRJUNCTION` | สามแยก สี่แยก วงเวียนสี่แขน และช่องเลี้ยวพร้อมช่วงเปลี่ยนความกว้าง |
| Edit Corridor | `SREDIT` | แก้หน้าตัดหลัก เพิ่ม แก้ หรือลบช่วงเฉพาะ ดูตัวอย่าง และสร้างเส้นใหม่จากแนวเดิม |

1. เปิดเครื่องมือ เลือกรูปแบบ แล้วปรับรายการฝั่งซ้ายหรือขวาของแนวจากหน้าต่างหน้าตัด องค์ประกอบเรียงจากแนวอ้างอิงออกไปด้านนอก ใช้ **Add Left**, **Add Right**, **Insert Before**, **Update Selected** หรือ **Remove** ตามงาน ค่าเริ่มต้นใช้หน่วยเดียวกับแบบ ให้ปรับค่าตัวเลขตามหน่วยของโครงการ
2. กรอกชื่อในช่อง **Template** แล้วใช้ **Save** บันทึก หรือ **Load** เรียกแม่แบบจากโปรไฟล์ AutoCAD ของผู้ใช้
3. วาดแนวใหม่ด้วย **Draw** หรือเลือกแนวเปิดชนิด LINE, ARC หรือ LWPOLYLINE ด้วย **Select** รูปทรงต้องอยู่ในระนาบ XY ของ WCS ฝั่งซ้ายและขวาอิงตามทิศจากต้นไปปลายแนว กด **Preview** เพื่อตรวจเส้นตัวอย่าง แล้วกด **Build** เพื่อสร้างเส้นแยกตามเลเยอร์
4. ใช้ **Edit Corridor** แล้วเลือกแนวอ้างอิงเดิม ใช้ **Section** เพื่อกำหนดระยะต้นและปลายที่วัดจากต้นแนว กำหนดหน้าตัดเฉพาะช่วง แล้วใส่ระยะเปลี่ยนความกว้างที่ปลายแต่ละด้าน ใช้ **Modify** เพื่อแก้ช่วงเดิม เมื่อปรับรูปแนวอ้างอิง ให้ใช้ **Rebuild** เพื่อสร้างผลลัพธ์ตามแนวล่าสุด
5. สำหรับสัญลักษณ์และทางแยก ให้เลือกจุดวาง จุดบอกทิศ และขนาดตามคำถามบนบรรทัดคำสั่ง ทางข้ามให้ชี้จากขอบถนนข้ามไปอีกฝั่ง ส่วนสามแยกให้ชี้ตามถนนหลัก โดยแขนแยกจะอยู่ด้านซ้ายของทิศที่ชี้

หน้าตัดและช่วงแก้ไขบันทึกกับแนวอ้างอิงใน DWG ขอบบนแนวโค้งสร้างเป็นโพลีไลน์ตามจุดตัวอย่าง ทางแยกที่วางด้วย `SRJUNCTION` เป็นเรขาคณิตแยกสำหรับจัดวางในแปลน ใช้ `SRCONNECT` เชื่อมคู่ขอบเส้นตรงกับแบบเดิมทีละมุม ระดับถนน ความลาดขวาง และความลาดทางลาดเป็นงานออกแบบระดับที่อยู่นอกขอบเขตของเครื่องมือแปลนชุดนี้

## ใช้งานผ่านหน้าต่าง

พิมพ์ `SMARTROAD` เพื่อเปิดหน้าต่างตั้งค่า ใส่ความกว้างเต็มในช่อง **Full road width** และรัศมีมุมทางแยกในช่อง **Junction fillet radius** ทั้งสองค่าใช้หน่วยของแบบ ตั้งรัศมีเป็น 0 เพื่อเก็บมุมเหลี่ยม

- **Draw centerline** ปิดหน้าต่างและเริ่มวาดแนวศูนย์กลางด้วย `PLINE`
- **Select centerlines** ปิดหน้าต่างและให้เลือกแนวศูนย์กลางเดิมในแบบ
- **Cancel** หรือ Esc ปิดหน้าต่างโดยไม่เปลี่ยนค่าและไม่เริ่มวาด

## ใช้งานผ่านบรรทัดคำสั่ง

- `DROAD` รับความกว้างเต็มและรัศมีมุมโค้งในหน่วยของแบบ จากนั้นใช้ `PLINE` วาดแนวศูนย์กลาง เลือกตัวเลือก Arc ของ PLINE เพื่อวาดช่วงโค้ง
- `RNET` รับค่าเดียวกันแล้วให้เลือกแนวศูนย์กลางเดิมชนิด LINE, ARC หรือ LWPOLYLINE ใน Model Space คำสั่งข้ามเส้นที่มีข้อมูลความกว้างของ Smart Road อยู่แล้ว
- ค่าเริ่มต้นคือความกว้าง 6 และรัศมี 3 กด Enter เพื่อใช้ค่าปัจจุบัน ตั้งรัศมีเป็น 0 เพื่อเก็บมุมเหลี่ยม
- แนวศูนย์กลางอยู่บนเลเยอร์ `ROAD-CENTER` และขอบอยู่บน `ROAD-EDGE` ใช้แนวศูนย์กลางระนาบ XY ที่ระดับเดียวกันสำหรับถนนที่จะตัดกัน มุมโค้งที่ทางแยกสร้างเมื่อขอบตรงสองเส้นมาบรรจบกันและมีความยาวพอสำหรับรัศมีที่ตั้งไว้
- ใช้ `U` เพื่อย้อนการเปลี่ยนแปลงของการรันหนึ่งครั้ง หากคำสั่งรายงานข้อผิดพลาดระหว่างประมวลผล ให้กด `U` ก่อนลองใหม่

## ตรวจบน AutoCAD 2016

1. เปิดแบบเปล่า โหลดปลั๊กอิน แล้วตรวจว่าบรรทัดคำสั่งแสดง `Smart Road loaded`
2. ใช้ `SMARTROAD` ลองใส่ความกว้าง 0 และกด **Draw centerline** ตรวจว่าหน้าต่างแจ้งข้อผิดพลาดและยังเปิดอยู่ ใส่ความกว้าง 6 แล้วกดปุ่มอีกครั้งเพื่อวาดเส้นจาก (0,0) ถึง (50,0) ด้วยความกว้าง 6 ตรวจว่าขอบสองด้านอยู่ห่างแนวศูนย์กลางด้านละ 3 หน่วย
3. สร้าง LINE จาก (25,-25) ถึง (25,25) แล้วเปิด `SMARTROAD` และใช้ **Select centerlines** เลือกเส้นนั้น ตรวจช่องเปิดที่ทางแยกและมุมโค้ง จากนั้นใช้ `U` ตรวจว่าแบบย้อนกลับไปก่อนรัน `RNET`
4. เปิด `SMARTROAD` แก้ค่าแล้วกด Esc เปิดใหม่และตรวจว่าค่าเดิมยังอยู่ จากนั้นทดลอง `DROAD` และ `RNET` ผ่านบรรทัดคำสั่ง

5. ใช้ `SMARTROADTOOLBAR` ตรวจไอคอนทั้งสามและกดแต่ละปุ่ม ตรวจว่าเปิดหน้าต่างหรือเรียกคำสั่งตามที่ระบุ แล้วโหลด LSP ซ้ำเพื่อตรวจว่ามีแถบ Smart Road เพียงแถบเดียว

6. วาด LINE ยาว 100 หน่วย ใช้ `SRROAD` สร้างถนนสองทาง แล้วใช้ `SREDIT` เพิ่มช่อง Bus ทางซ้ายช่วง 20–50 โดยกำหนดช่วงเปลี่ยนความกว้าง 5 หน่วย ตรวจขอบก่อนและหลังช่วง แล้วบันทึก DWG เปิดใหม่และสั่ง Rebuild
7. ทดลองวางทางข้าม ทางลาด ป้าย ชานชาลา และทางแยกทั้งสี่ตัวเลือก พร้อมตรวจขนาดและทิศหมุน

ตรวจโครงสร้าง AutoLISP, XML, ไอคอน BMP และแพ็กเกจแล้ว ทดสอบจำลองการสร้างขอบและช่วงเปลี่ยนความกว้าง การตัดและยืดมุม การเก็บข้อมูลแนวต้นทาง การวัดความยาวและพื้นที่ และการส่งออกตารางกับ CSV การตรวจการโหลด ปุ่มบนแถบ และผลลัพธ์ใน DWG ต้องใช้ AutoCAD 2016 บน Windows


## ทดสอบความเร็วในงานจริง

ใช้สำเนา DWG เดียวกันเปรียบเทียบ AutoCAD ปกติกับ Smart Road และจับเวลารวมตั้งแต่เริ่มตั้งค่าจนตรวจแบบเสร็จ ตัวอย่างแรกคือสร้างแนวถนนห้าเส้นจากหน้าตัดเดียวกันและย้อนด้วย `U` ครั้งเดียว ตัวอย่างที่สองคือเพิ่มช่องรถเมล์ระหว่างจุดสองจุดบนถนนแล้วตรวจช่วงเปลี่ยนความกว้าง เปรียบเทียบทั้งรอบตั้งค่าใหม่และรอบที่ใช้ค่าเดิม หากเวลารวมเท่ากันหรือมากขึ้น ให้นับเวลาที่ประหยัดได้เป็น 0% สำหรับงานนั้น


## ตรวจการเชื่อมขอบและปริมาณใน AutoCAD 2016

1. วาด LINE สองเส้นตัดกันใน Model Space ใช้ **Connect Edges** เลือกด้านที่เก็บทั้งสองเส้น ตรวจผลตัวอย่างแล้วกดยกเลิก ตรวจว่าขอบเดิมยังอยู่ จากนั้นทำซ้ำและยืนยัน ตรวจว่าปลายชนกันและย้อนด้วย `U` ได้
2. สร้างแนวถนนตรงพร้อมทางเท้าด้วย Smart Road เลือกแนวอ้างอิงและขอบพร้อมกันแล้วสั่ง **Quantities → Corridors** ตรวจว่านับเป็นแนวเดียว เทียบผลกับตัวอย่างทางเท้ากว้าง 2 หน่วยและยาว 100 หน่วยบนแนวตรง ซึ่งมีพื้นที่ 200 ตารางหน่วยต่อฝั่ง
3. ใช้ **Quantities → Existing** กับ LINE และโพลีไลน์ปิด ตรวจคอลัมน์ความยาวและพื้นที่ เทียบค่าระหว่างตารางใน DWG และไฟล์ CSV
4. ใช้ **Connect Edges** ตัดขอบของแนว Smart Road เข้ากับขอบถนนเดิม จากนั้นออกรายงานใหม่เพื่อตรวจความยาวขอบที่ตัดแล้ว เมื่อสั่ง Rebuild ให้ตรวจว่ามีข้อความยืนยันก่อนแทนที่มุมที่ตัดไว้
