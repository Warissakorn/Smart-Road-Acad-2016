# Smart Road 2.4 สำหรับ AutoCAD 2016

รองรับ AutoCAD 2016 รุ่นเต็มบน Windows ใช้ AutoLISP และ Visual LISP/ActiveX โดยโหลดไฟล์ `Smart Road.lsp` ได้โดยตรง

[แนวทางพัฒนาปลั๊กอินและรายละเอียดทางเทคนิค](docs/DEVELOPMENT.th.md)

## ติดตั้ง

- ใช้ `APPLOAD` แล้วเลือก `Smart Road.lsp` จากโฟลเดอร์ที่เชื่อถือได้ตามการตั้งค่า `TRUSTEDPATHS`
- สำหรับโหลดอัตโนมัติ ให้ปิด AutoCAD แล้วคัดลอกโฟลเดอร์ `SmartRoad.bundle` ทั้งโฟลเดอร์ไปไว้ใน `%APPDATA%\Autodesk\ApplicationPlugins` หากลงรุ่นเดิมไว้ ให้แทนที่โฟลเดอร์เดิมด้วยโฟลเดอร์รุ่นนี้ จากนั้นเปิด AutoCAD ใหม่

### ตัวติดตั้ง Windows จาก GitHub Actions

ดาวน์โหลดไฟล์ `Setup.exe` หรือ ZIP จากแท็บ **Releases** เมื่อ push แท็กที่ตรงกับ `AppVersion` ใน manifest เช่น `v2.4.2` workflow **Release Smart Road installer** จะทดสอบบน Windows แล้วแนบไฟล์ทั้งสองไปยัง GitHub Releases โดยตรง

Workflow **Build Smart Road installer** ตรวจการสร้างและติดตั้งเมื่อ push เข้า `main` หากต้องการแนบไฟล์ผ่าน **Actions → Artifacts** ให้เลือก **Run workflow** แล้วเปิดตัวเลือก **Upload EXE and ZIP to Actions Artifacts if storage is available** การแนบผ่าน Actions จะใช้โควตาพื้นที่ของ GitHub Actions

ปิด AutoCAD ก่อนเปิด Setup ตัวติดตั้งใช้โฟลเดอร์ Bundle เดิมสำหรับบัญชี Windows ปัจจุบันและใช้รายการถอนการติดตั้งเดิมเมื่ออัปเกรดจาก Setup รุ่นก่อน หากพบ Bundle ที่เคยคัดลอกจาก ZIP ก็จะแจ้งก่อนลงทับ ไฟล์อื่นในโฟลเดอร์ที่ตัวติดตั้งไม่ได้จัดการจะยังอยู่ ข้อมูลใน DWG และแม่แบบที่บันทึกในโปรไฟล์ AutoCAD ไม่ต้องย้าย

## แท็บ Smart Road บน Ribbon

เมื่อวาง `SmartRoad.bundle` รุ่นนี้ในโฟลเดอร์ ApplicationPlugins แล้วเปิด AutoCAD 2016 ใหม่ ให้คลิกแท็บ **Smart Road** ที่แถวเดียวกับ **Home** และ **Insert** ตำแหน่งในแถวขึ้นอยู่กับ Workspace และปลั๊กอินอื่นในเครื่อง

| กลุ่มบน Ribbon | ปุ่มและคำสั่ง |
|---|---|
| **Roads** | **Draw Road** (`SRDRAWROAD`), **Build from Alignments** (`SRBUILDROAD`), **Cross Sections** (`SRPROFILE`) |
| **Corridor** | **Edit Corridor** (`SREDIT`), **Edit by Points** (`SRSECTION`) |
| **Junctions** | **Junction Layout** (`SRJUNCTION`), **Join Road Edges** (`SRCONNECT`) |
| **Walk & Transit** | **Pedestrian Layout** (`SRWALK`), **Transit Layout** (`SRTRANSIT`) |
| **Finish** | **Surface & Markings** (`SRSTYLE`) |

ถ้า Ribbon ถูกปิด ให้พิมพ์ `RIBBON` หากยังไม่เห็นแท็บ Smart Road ให้ตรวจเมนู **Show Tabs** จากการคลิกขวาที่ Ribbon หรือใช้ `CUILOAD` เลือก `SmartRoad.bundle/Contents/SmartRoadRibbon.cuix` วิธี `APPLOAD` ต้องโหลดทั้งไฟล์ LSP และไฟล์ CUIX แยกกัน

ไฟล์ CUIX เป็นส่วนเสริมของ Smart Road และใช้ไอคอนของ Smart Road เอง ผู้พัฒนาสร้างใหม่ได้ด้วย `python tools/build_ribbon.py` เมื่อเปลี่ยนปุ่มหรือไอคอน โครงสร้าง CUIX อ้างอิงตัวอย่างของ [Autodesk Developer Network](https://github.com/ADN-DevTech/acad-cuix-builder) ภายใต้ MIT

### สร้างและแก้แปลน

1. กด **Cross Sections** เพื่อตั้งหน้าตัดที่จะใช้ หรือบันทึกและโหลดแม่แบบตามชื่อ เมื่อเปิด **Draw Road** หรือ **Build from Alignments** โปรแกรมจะแสดงหน้าตัดล่าสุด เลือก **Active** เพื่อใช้ชุดนี้ หรือ **Configure** เพื่อปรับใหม่
2. กด **Draw Road** เพื่อวาดแนวตรงหลายช่วง เลือกรูปแบบผิวทางและเส้นจราจรก่อนคลิกจุดเริ่ม ขณะลากจะเห็นขอบและตำแหน่งเส้นตี กด Backspace เพื่อลบจุดล่าสุด Enter เพื่อจบแนว หรือ Esc เพื่อยกเลิก
3. หากมีแนวอยู่แล้ว ใช้ **Build from Alignments** เลือก LINE, ARC หรือ LWPOLYLINE แบบเปิดหนึ่งเส้นหรือหลายเส้น เลือกเส้นก่อนกดปุ่มได้ ตรวจภาพตัวอย่างและความกว้างรวม แล้วกด **Build**
4. ใช้ **Edit Corridor** สำหรับแก้หน้าตัดหลักและกำหนดช่วงด้วยตัวเลข หรือ **Edit by Points** เพื่อคลิกต้น–ปลายช่วง ทั้งสองปุ่มและ **Surface & Markings** เลือกแนวอ้างอิง ขอบ หรือพื้นสีของ Corridor ได้
5. ใช้ **Junction Layout → FromRoads** จัดทางแยก 3 หรือ 4 แขนจากแนวจริง หรือเลือกแม่แบบทางแยก จากนั้นใช้ **Join Road Edges** เชื่อมขอบทีละมุม แล้วตรวจผิวทางและเส้นตีด้วย **Surface & Markings**

ภาพตัวอย่างเป็นเส้นชั่วคราว ผิวทางและเส้นตีจริงจะถูกสร้างเมื่อกด **Build** หากแนวหักจนรักษาระยะเยื้องไม่ได้ โปรแกรมแจ้งตำแหน่งก่อนสร้าง แนวยาวมากอาจเว้นเส้นประในภาพตัวอย่างเพื่อให้ลากได้ต่อเนื่อง หน้าตัดใช้หน่วยของ DWG หากต้องวาดโค้งใหม่ ใช้ `PLINE` หรือ `ARC` เตรียมแนวแล้วเรียก **Build from Alignments**

ปลั๊กอินจะซ่อน Toolbar ตอนโหลด พิมพ์ `SMARTROADTOOLBAR` เพื่อเปิดแถบปุ่มชุดเดียวกับ Ribbon หากมีหน้าต่างเลือกไฟล์ ให้เลือก `SmartRoadStyle16.bmp` ใน `SmartRoad.bundle/Contents/Icons` ปิดและเปิด AutoCAD ใหม่เมื่อแทนที่ Bundle จากรุ่นก่อน

## พื้นถนนและเส้นจราจร

1. สร้าง Corridor ด้วย **Draw Road** หรือ **Build from Alignments**
2. กด **Surface & Markings** (`SRSTYLE`) แล้วคลิกแนวอ้างอิง ขอบ หรือพื้นสีของถนน เลือก **YellowDash** สำหรับเส้นกลางเหลืองประ, **DoubleYellow** สำหรับเส้นคู่เหลืองทึบ, **WhiteDash** สำหรับเส้นกลางขาวประ หรือ **NoCenter** เพื่อเว้นเส้นกลาง เลือก **Clear** เพื่อลบพื้นและเส้นตีของแนวที่เลือก
3. ปลั๊กอินถมพื้นแบบ `SOLID HATCH` และวางเส้นขาวทึบที่ขอบช่องกับเส้นขาวประระหว่างช่องติดกัน สีพื้นแอสฟัลต์ คอนกรีต ช่องจักรยาน และช่องรถโดยสารแก้ได้ใน Layer Properties ที่เลเยอร์ `SR-FILL-*` เส้นตีแยกใน `SR-MARK-*` ทางข้ามใหม่จาก `SRWALK` มีพื้นสีขาวทึบ

การเรียก Surface & Markings ซ้ำแทนที่งานสีเดิมของแนวเดียวกัน และ Edit Corridor จะสร้างงานสีเดิมใหม่เมื่อขอบยังตรวจสอบได้ เมื่อใช้ **Join Road Edges** ภาพตัวอย่างสีม่วงแสดงช่วงสถานีที่จะเว้นผิวทางและเส้นตี โปรแกรมสร้างงานสีใหม่ให้ส่วนที่ตรวจสอบได้ของช่วงเดิม ส่วนมุมที่เชื่อมให้จัดผิวทางตามแบบ หาก DWG รุ่นเก่าเก็บเพียงเครื่องหมายว่าช่วงถูกตัด โปรแกรมจะเว้นทั้งช่วงนั้นตามข้อมูลเดิม เส้นขอบทางจะเยื้องเข้าในผิวทางตามครึ่งความกว้างเส้น และเส้นที่วางไม่พอดีกับผิวทางจะถูกเว้นพร้อมแจ้งช่วงสถานี

สำหรับค่าเริ่มต้นให้ตั้ง `INSUNITS` ให้ตรงกับหน่วยของแบบ โปรแกรมแปลงขนาดแม่แบบ built-in และขนาดเส้นตีจากเมตรเป็นหน่วย DWG ที่รองรับ Quick Build และแม่แบบที่บันทึกตั้งแต่รุ่น 2.4.1 แปลงความกว้างตามหน่วยของแบบปลายทาง ค่า Quick Build จากรุ่นเก่าจะเริ่มใหม่ด้วยหน้าตัดมาตรฐาน ส่วนแม่แบบเดิมที่เรียกด้วยชื่อยังใช้ตัวเลขเดิม ให้เปิดในแบบหน่วยเดิมแล้วบันทึกแม่แบบอีกครั้งก่อนใช้ข้ามหน่วย ขนาดเริ่มต้นคือเส้นกว้าง 0.12 ม. เส้นประยาว 3 ม. เว้น 6 ม. และเส้นคู่มีช่องว่างระหว่างขอบเส้น 0.12 ม. หลังเลือกรูปแบบใน Surface & Markings ให้เลือก **Set** เพื่อใส่ค่าตามโครงการเป็นเมตร หรือ **Keep** เพื่อใช้ค่าเดิมของ Corridor ขนาดพื้นอิงจากหน้าตัด หากความกว้างพื้นผิด ให้แก้ความกว้างแต่ละส่วนด้วย Edit Corridor ก่อน

## เชื่อมขอบถนนในแบบเดิม

1. กด **Join Road Edges** (`SRCONNECT`) แล้วคลิกขอบถนนสองเส้นด้านที่ต้องการเก็บไว้ เครื่องมือใช้แนวเส้นจริงใน DWG เพื่อหามุมที่จะเชื่อม
2. ตรวจเส้นตัวอย่างแล้วเลือก **Apply** เพื่อยืนยัน หรือกด Esc เพื่อยกเลิก ใช้ `U` ครั้งเดียวเพื่อย้อนการแก้มุมนั้น
3. ทำซ้ำที่มุมอื่นของสามแยกหรือสี่แยกตามต้องการ

รองรับขอบที่วาดด้วย LINE และ LWPOLYLINE แบบเส้นตรงบนระนาบแนวนอนเดียวกัน โปรแกรมตัดส่วนเกินที่ตัดกัน หรือยืดช่วงตรงที่ปลายเส้นไปหาจุดตัด โดยแจ้งระยะยืดในภาพตัวอย่าง สำหรับเส้นที่ Smart Road สร้าง โปรแกรมเก็บข้อมูลแนวต้นทางไว้และทำเครื่องหมายมุมที่ตัดแล้ว หากสร้างช่วงที่แก้ใหม่ภายหลัง โปรแกรมจะแจ้งก่อนแทนที่งานตัดมุมนั้น มุมโค้งใช้กับคู่เส้นทั่วไปที่มีระยะพอสร้างรัศมีได้ เมื่อเลือก ARC ให้เลือกคู่ขอบที่ตัดกันอยู่แล้ว โปรแกรมเก็บส่วนโค้งด้านที่คลิกและตัดที่จุดตัดใกล้ตำแหน่งที่เลือกที่สุด

## ขั้นตอนแบบเร็ว

### สร้างถนนและทางเท้าหลายแนว

1. ตั้งหน้าตัดครั้งแรกด้วย `SRPROFILE` หรือเปิด **Cross Sections** หน้าต่างแสดงองค์ประกอบซ้าย–ขวาพร้อมกัน แก้ชนิด ความกว้าง และลำดับได้จากหน้าต่างเดียว
2. เลือกแนวเปิดใน Model Space หลายเส้น แล้วพิมพ์ `SRQUICK` โปรแกรมสร้างจากหน้าตัดล่าสุด ถ้ากดคำสั่งก่อนเลือกแนว จะเข้าสู่โหมดเลือกแนวได้เลย
3. ใช้ `U` ครั้งเดียวเพื่อย้อนการสร้างทั้งชุด แนวที่สร้างถนนไว้แล้ว แนวปิด หรือแนวที่อยู่บนเลเยอร์ล็อกจะถูกข้ามและรายงานจำนวน

การสร้างถนนด้วย `SRROAD`, **Pedestrian Layout** หรือ **Transit Layout** จากหน้าตัดสำเร็จ จะบันทึกหน้าตัดนั้นสำหรับ Quick Build ครั้งถัดไปด้วย ค่าเริ่มแรกหากยังไม่เคยตั้งหน้าตัดคือช่องกว้าง 3.5 เมตรฝั่งละหนึ่งช่อง แปลงตามหน่วยของแบบที่รองรับ

### คลิกกำหนดช่วงแก้หน้าตัด

1. กด **Edit by Points** (`SRSECTION`) เลือกแนวอ้างอิงของถนน แล้วคลิกจุดต้นและจุดปลายช่วงบนแบบ โปรแกรมฉายตำแหน่งเข้าหาแนวและคำนวณระยะตามแนวให้
2. เลือก **Bus**, **Walkway**, **Parking** หรือ **Cycle** เพื่อเพิ่มองค์ประกอบที่ด้านนอกหน้าตัด หรือเลือก **Profile** เพื่อแก้รายการทั้งหมด กำหนดฝั่ง ความกว้าง และความยาวช่วงเปลี่ยนความกว้างตามลำดับ
3. ตรวจเส้นตัวอย่างแล้วกด **Build** หรือ **Cancel** หากช่วงที่เลือกทับช่วงเดิมหนึ่งช่วง เลือก **Keep** เพื่อเก็บช่วงด้านนอก หรือ **Replace** เพื่อแทนที่ช่วงเดิมทั้งหมด ภาพตัวอย่างแสดงขอบและช่วงเปลี่ยนที่ได้รับผล ระยะ taper ของแต่ละช่วงย่อยอาจสั้นลงตามความยาวที่เหลือ

การแก้แบบจะเก็บช่วงที่ไม่เปลี่ยนไว้ เส้นเดิมที่พาดผ่านขอบเขตช่วงแก้อาจต้องแบ่งและสร้างใหม่ เมื่อแก้แนวที่สร้างด้วยรุ่นเก่าครั้งแรก หรือแนวที่ถูกปรับรูปทรงจากครั้งก่อน โปรแกรมจะสร้างขอบของแนวนั้นใหม่ทั้งหมดหนึ่งครั้ง ใช้ **Edit Corridor → Section** สำหรับงานที่ต้องป้อนระยะตัวเลขโดยตรง

## เครื่องมือวางแปลน 2D

| ปุ่ม | คำสั่ง | รูปแบบ |
|---|---|---|
| Road Corridor | `SRROAD` | ถนนทางเดียว สองทาง มีเกาะกลาง หรือถนนพร้อมช่องจอด ช่องจักรยาน คันหิน และทางเท้า |
| Pedestrian Layout | `SRWALK` | ทางเท้าข้างเดียว สองข้าง หรือทางเดินอิสระ รวมถึงทางข้าม เกาะพัก และสัญลักษณ์ทางลาด |
| Transit Layout | `SRTRANSIT` | ช่องรถเมล์ ช่อง BRT แนวรางเดี่ยวหรือรางคู่ ตำแหน่งป้ายหยุดรถ และชานชาลา |
| Junction Layout | `SRJUNCTION` | สามแยก สี่แยก วงเวียนสี่แขน และช่องเลี้ยวพร้อมช่วงเปลี่ยนความกว้าง |
| Edit Corridor | `SREDIT` | แก้หน้าตัดหลัก เพิ่ม แก้ หรือลบช่วงเฉพาะ ดูตัวอย่าง และสร้างเส้นใหม่จากแนวเดิม |

1. เปิดเครื่องมือ เลือกรูปแบบ แล้วปรับรายการฝั่งซ้ายหรือขวาของแนวจากหน้าต่างหน้าตัด องค์ประกอบเรียงจากแนวอ้างอิงออกไปด้านนอก ใช้ **Add Left**, **Add Right**, **Insert Before**, **Update Selected** หรือ **Remove** ตามงาน ค่าเริ่มต้นใช้หน่วยเดียวกับแบบ ให้ปรับค่าตัวเลขตามหน่วยของโครงการ
2. กรอกชื่อในช่อง **Template** แล้วใช้ **Save** บันทึก หรือ **Load** เรียกแม่แบบจากโปรไฟล์ AutoCAD ของผู้ใช้
3. วาดแนวใหม่ด้วย **Draw** หรือเลือกแนวเปิดชนิด LINE, ARC หรือ LWPOLYLINE ด้วย **Select** รูปทรงต้องอยู่ในระนาบ XY ของ WCS ฝั่งซ้ายและขวาอิงตามทิศจากต้นไปปลายแนว กด **Preview** เพื่อตรวจเส้นตัวอย่าง แล้วกด **Build** เพื่อสร้างเส้นแยกตามเลเยอร์
4. ใช้ **Edit Corridor** แล้วเลือกแนวอ้างอิงเดิม ใช้ **Section** เพื่อกำหนดระยะต้นและปลายที่วัดจากต้นแนว กำหนดหน้าตัดเฉพาะช่วง แล้วใส่ระยะเปลี่ยนความกว้างที่ปลายแต่ละด้าน ใช้ **Modify** เพื่อแก้ช่วงเดิม เมื่อปรับรูปแนวอ้างอิง ให้ใช้ **Rebuild** เพื่อสร้างผลลัพธ์ตามแนวล่าสุด หากแนวใหม่สั้นลงจนกระทบช่วงที่บันทึก โปรแกรมแจ้งช่วงที่จะสั้นลงหรือถูกเว้นก่อนยืนยัน
5. สำหรับสัญลักษณ์และทางแยก ให้เลือกจุดวาง จุดบอกทิศ และขนาดตามคำถามบนบรรทัดคำสั่ง ทางข้ามให้ชี้จากขอบถนนข้ามไปอีกฝั่ง ส่วนสามแยกให้ชี้ตามถนนหลัก โดยแขนแยกจะอยู่ด้านซ้ายของทิศที่ชี้

หน้าตัดและช่วงแก้ไขบันทึกกับแนวอ้างอิงใน DWG แนวตรงใช้เฉพาะจุดปลายและจุดหัก ส่วนแนวอ้างอิง ARC ที่หน้าตัดคงที่ให้ขอบ ARC จริง ช่วงเปลี่ยนหน้าตัดบนโค้งและโค้งในโพลีไลน์ใช้จุดตัวอย่างตามความโค้ง ทางแยกที่วางด้วย `SRJUNCTION` เป็นเรขาคณิตแยกสำหรับจัดวางในแปลน ใช้ `SRCONNECT` เชื่อมคู่ขอบกับแบบเดิมทีละมุม ระดับถนน ความลาดขวาง และความลาดทางลาดเป็นงานออกแบบระดับที่อยู่นอกขอบเขตของเครื่องมือแปลนชุดนี้

### ทางแยกจากแนวจริงและสัญลักษณ์ขนส่งที่ผูกกับแนว

- **Junction Layout → FromRoads** ให้ระบุจุดกลางที่อยู่บนแนวถนน แล้วคลิกแนวแต่ละแขนด้านที่จะออกจากทางแยก ระยะที่คลิกกำหนดความยาวแขน คำสั่งใช้ทิศสัมผัสที่ทางแยกและความกว้างสองฝั่งของ Corridor ณ ตำแหน่งนั้น สำหรับแนวทั่วไปให้กรอกความกว้างของแต่ละแขน จากนั้นตรวจภาพตัวอย่างก่อน **Apply**
- **Transit Layout → LinkedStop / LinkedPlatform** ให้เลือก Corridor คลิกสถานีกึ่งกลาง เลือกฝั่ง และตั้งระยะร่นจากขอบ วัตถุจะปรับทิศและตำแหน่งเมื่อใช้ **Edit Corridor** หรือ **Edit by Points** หากสถานีอยู่นอกแนวที่ย่อแล้ว ให้ลบสัญลักษณ์เดิมแล้ววางใหม่ สำหรับ LinkedStop ให้เลือกทั้งกรอบและจุดป้าย ตัวเลือก **Stop / Platform** วางสัญลักษณ์อิสระ
- ตรวจหน่วยใน DWG และความกว้างก่อน Build โดยเฉพาะแม่แบบเก่าที่ไม่มีข้อมูลหน่วย ทางข้ามที่กว้างหรือแคบจนจำนวนแถบเกินช่วงคำนวณ หรืออยู่ในแบบที่ไม่ระบุหน่วย จะให้ตรวจค่าก่อนยืนยัน

## คำสั่งเพิ่มเติม

- `SRCREATEROAD` ใช้ขั้นตอน Draw / Select ภายในคำสั่งเดียว
- `SRROAD` สร้าง Corridor ทีละแนว ใช้ Draw เพื่อวาดด้วย `PLINE` ได้
- `SRQUICK` สร้างขอบหลายแนวจากหน้าตัดล่าสุดด้วยคำสั่งเดียว

### ตั้งค่าถนนแบบความกว้างเดียว

พิมพ์ `SMARTROAD` เพื่อเปิดหน้าต่างตั้งค่า ใส่ความกว้างเต็มในช่อง **Full road width** และรัศมีมุมทางแยกในช่อง **Junction fillet radius** ทั้งสองค่าใช้หน่วยของแบบ ตั้งรัศมีเป็น 0 เพื่อเก็บมุมเหลี่ยม

- **Draw centerline** ปิดหน้าต่างและเริ่มวาดแนวศูนย์กลางด้วย `PLINE`
- **Select centerlines** ปิดหน้าต่างและให้เลือกแนวศูนย์กลางเดิมในแบบ
- **Cancel** หรือ Esc ปิดหน้าต่างโดยไม่เปลี่ยนค่าและไม่เริ่มวาด

### วาดถนนแบบความกว้างเดียวผ่านบรรทัดคำสั่ง

- `DROAD` รับความกว้างเต็มและรัศมีมุมโค้งในหน่วยของแบบ จากนั้นใช้ `PLINE` วาดแนวศูนย์กลาง เลือกตัวเลือก Arc ของ PLINE เพื่อวาดช่วงโค้ง
- `RNET` รับค่าเดียวกันแล้วให้เลือกแนวศูนย์กลางเดิมชนิด LINE, ARC หรือ LWPOLYLINE ใน Model Space คำสั่งข้ามแนวที่จัดการอยู่แล้ว รวมถึงแนว ขอบ และพื้นสีของ Corridor
- ค่าเริ่มต้นคือความกว้าง 6 และรัศมี 3 กด Enter เพื่อใช้ค่าปัจจุบัน ตั้งรัศมีเป็น 0 เพื่อเก็บมุมเหลี่ยม
- แนวศูนย์กลางอยู่บนเลเยอร์ `ROAD-CENTER` และขอบอยู่บน `ROAD-EDGE` ใช้แนวศูนย์กลางระนาบ XY ที่ระดับเดียวกันสำหรับถนนที่จะตัดกัน มุมโค้งที่ทางแยกสร้างเมื่อขอบตรงสองเส้นมาบรรจบกันและมีความยาวพอสำหรับรัศมีที่ตั้งไว้
- ใช้ `U` เพื่อย้อนการเปลี่ยนแปลงของการรันหนึ่งครั้ง หากคำสั่งรายงานข้อผิดพลาดระหว่างประมวลผล ให้กด `U` ก่อนลองใหม่

## ตรวจบน AutoCAD 2016

1. เปิดแบบเปล่า โหลดปลั๊กอิน แล้วตรวจว่าบรรทัดคำสั่งแสดง `Smart Road loaded`
2. ใช้ `SMARTROAD` ลองใส่ความกว้าง 0 และกด **Draw centerline** ตรวจว่าหน้าต่างแจ้งข้อผิดพลาดและยังเปิดอยู่ ใส่ความกว้าง 6 แล้วกดปุ่มอีกครั้งเพื่อวาดเส้นจาก (0,0) ถึง (50,0) ด้วยความกว้าง 6 ตรวจว่าขอบสองด้านอยู่ห่างแนวศูนย์กลางด้านละ 3 หน่วย
3. สร้าง LINE จาก (25,-25) ถึง (25,25) แล้วเปิด `SMARTROAD` และใช้ **Select centerlines** เลือกเส้นนั้น ตรวจช่องเปิดที่ทางแยกและมุมโค้ง จากนั้นใช้ `U` ตรวจว่าแบบย้อนกลับไปก่อนรัน `RNET`
4. เปิด `SMARTROAD` แก้ค่าแล้วกด Esc เปิดใหม่และตรวจว่าค่าเดิมยังอยู่ จากนั้นทดลอง `DROAD` และ `RNET` ผ่านบรรทัดคำสั่ง

5. ใช้ `SMARTROADTOOLBAR` ตรวจว่ามี 10 ปุ่มตามตารางและกดแต่ละปุ่ม ตรวจว่าเปิดหน้าต่างหรือเรียกคำสั่งตามที่ระบุ แล้วโหลด LSP ซ้ำเพื่อตรวจว่ามีแถบ Smart Road เพียงแถบเดียว

6. วาด LINE ยาว 100 หน่วย ใช้ `SRROAD` สร้างถนนสองทาง แล้วใช้ `SREDIT` เพิ่มช่อง Bus ทางซ้ายช่วง 20–50 โดยกำหนดช่วงเปลี่ยนความกว้าง 5 หน่วย ตรวจขอบก่อนและหลังช่วง แล้วบันทึก DWG เปิดใหม่และสั่ง Rebuild
7. ทดลองวางทางข้าม ทางลาด ป้าย ชานชาลา และทางแยกทั้งสี่ตัวเลือก พร้อมตรวจขนาดและทิศหมุน

ตรวจโครงสร้าง AutoLISP, XML, ไอคอน BMP และแพ็กเกจแล้ว ทดสอบจำลองการสร้างขอบและช่วงเปลี่ยนความกว้าง การตัดและยืดมุม และการเก็บข้อมูลแนวต้นทาง การตรวจการโหลด ปุ่มบนแถบ และผลลัพธ์ใน DWG ต้องใช้ AutoCAD 2016 บน Windows


## ทดสอบความเร็วในงานจริง

ใช้สำเนา DWG เดียวกันเปรียบเทียบ AutoCAD ปกติกับ Smart Road และจับเวลารวมตั้งแต่เริ่มตั้งค่าจนตรวจแบบเสร็จ ตัวอย่างแรกคือสร้างแนวถนนห้าเส้นจากหน้าตัดเดียวกันและย้อนด้วย `U` ครั้งเดียว ตัวอย่างที่สองคือเพิ่มช่องรถเมล์ระหว่างจุดสองจุดบนถนนแล้วตรวจช่วงเปลี่ยนความกว้าง เปรียบเทียบทั้งรอบตั้งค่าใหม่และรอบที่ใช้ค่าเดิม หากเวลารวมเท่ากันหรือมากขึ้น ให้นับเวลาที่ประหยัดได้เป็น 0% สำหรับงานนั้น


## ตรวจชุดเครื่องมือใหม่ใน AutoCAD 2016

1. ใช้ **Cross Sections** ตั้งและบันทึกหน้าตัด แล้วใช้ **Draw Road → Active** วาดแนวหักมุม ตรวจเส้นตัวอย่าง ใช้ Backspace แล้วทดสอบทั้ง Cancel และ Build ผลจาก Build ต้องย้อนด้วย `U` ครั้งเดียว
2. เลือก LINE และ ARC ไว้ก่อนกด **Build from Alignments** ตรวจว่าทั้งสองแนวถูกนำมาใช้ จากนั้นคลิกขอบหรือพื้นสีด้วย **Edit Corridor** และ **Edit by Points** เพื่อตรวจว่าเปิด Corridor เดียวกัน
3. ใช้ **Join Road Edges** กับขอบสองเส้น ทดลอง Cancel และ Apply ตรวจผลที่มุมและงานสี หลังเชื่อมแล้วสั่ง Rebuild เพื่อตรวจข้อความยืนยันก่อนแทนที่มุมที่เชื่อมไว้
4. เปิดแบบมิลลิเมตร วาง **Transit Layout → Stop** โดยรับค่าเริ่มต้น ตรวจว่าตัวสัญลักษณ์ยาว 12,000 มม.
5. เปิดรุ่นใหม่ทับรุ่นเดิม ตรวจว่ามีห้ากลุ่มบน Ribbon และ Toolbar แสดงเฉพาะปุ่มชุดปัจจุบัน


### แบบประกอบการตรวจบน Windows

เปิดแบบเปล่าใน Model Space โหลด `Smart Road.lsp` และ `tools/acad2016-smoke.lsp` ผ่าน `APPLOAD` แล้วพิมพ์ `SRSMOKE` เลือกเมตรหรือมิลลิเมตร ใช้แบบทดสอบแยกกันสำหรับแต่ละหน่วย

| ลองใน DWG | ผลที่ควรเห็น |
|---|---|
| เลือกแนว `SR-TEST-SHARP` ด้วย Build from Alignments | แนวหัก 160° แจ้งตำแหน่งและปฏิเสธก่อนสร้างขอบ |
| ตรวจแนว `SR-TEST-NARROW` | ผิวทางกว้างข้างละ 0.10 ม. มี Hatch และระบบแจ้งว่าเว้นเส้นที่วางไม่พอดี |
| ใช้ Join Road Edges กับขอบ `MAIN` และ `BRANCH` ใกล้จุดตัด | ดูช่วงสีม่วงก่อน Apply ผิวและเส้นตีที่พ้นช่วงตัดยังอยู่ กด `U` ครั้งเดียวเพื่อตรวจการคืนขอบและงานสี |
| เพิ่มหน้าตัดช่วง 20–50 ม. แล้วใช้ Edit by Points ช่วง 30–40 ม. และเลือก Keep | ตรวจช่วง 20–30 และ 40–50 ม. และตรวจรูปช่วงเปลี่ยนจากภาพตัวอย่างก่อน Build |
| วาง LinkedStop ฝั่งขวาของ MAIN ที่สถานี 35 ม. แล้วขยายหน้าตัดฝั่งขวา | ป้ายเลื่อนตามขอบ ตรวจ `U` แล้วบันทึก DWG เปิดใหม่และ Rebuild เพื่อดูว่าการผูกยังอยู่ |
| ใช้ FromRoads โดยคลิกแนวออกจากจุดที่ MAIN ตัด BRANCH | เลือกสามแขนแล้วดูภาพตัวอย่าง ใช้สำเนาแบบหมุนแนว BRANCH และแก้หน้าตัดก่อนทดสอบมุมเฉียงและความกว้างต่างกัน |
